# 食藥署食品營養資料完整覆蓋報告

本次以 2026-11-11 取得的[食藥署官方食品營養成分資料集 8543](https://data.gov.tw/dataset/8543)為準，
**2,213 個官方樣品全部有對應食物檔案，缺少 0 筆**。
沿用既有 139 筆 TFDA 樣品，新增 2,074 筆；原有 690 筆食物維持原樣，全站共 2,764 筆。

[下載完整樣品對照 CSV](TFDA_COVERAGE.csv)可依官方整合編號、原名、分類及檔案查找。
[機器可讀的完整覆蓋索引](sources/tfda-complete/index.json)包含所有樣品與來源檔案對應。

## 「全部」的範圍與去重

- 官方 ZIP 內 `20_2.csv` 共有 230,152 列分析資料，按「整合編號」分為 2,213 筆樣品，每筆 104 個分析欄位。
- 依官方樣品編號 `sampleId` 去重，沒有重建先前肉類專案的 139 筆 TFDA 樣品。
- 保留官方的平均值、不同品種、生熟、烘烤條件、加工配方、取樣年份與其他獨立樣品；這些不是同一個來源編號的重複資料。
- 既有 USDA、日本官方與其他資料仍保留。跨來源名稱相近不代表檢體相同，因此不以模糊名稱判斷「已收錄」。新資料若和既有顯示名稱完全相同，附上「食藥署樣品」區分。
- 本報告保證這次下載快照的完整覆蓋；不宣稱永久涵蓋食藥署將來新增的樣品，也不將下載日當成各樣品的檢驗日期。

## 營養數值、缺值與計重

- `per100g` 直接擷取「每100克含量」，基準為**可食部分**。來源樣品名稱、官方分類、英文名、俗名與前處理描述保留供核對。
- App 支援的 21 種營養素：熱量、蛋白質、脂肪、飽和脂肪、碳水、總糖、纖維、鈉、鉀、鈣、鐵、維生素 C、膽固醇、鋅、B1、B2、B6、B12、維生素 D、EPA、DHA。僅有原始數字的欄位才顯示。
- 使用「熱量」，不改用「修正熱量」或自行推算；「糖質總量」對應總糖，「總碳水化合物」另列，兩者不能互換。
- 原始空白省略，記錄於 `dataNotes.missingNutrients`；不以零代填。原始數字為零時才保留零。
- 蛋白質、脂肪、飽和脂肪、碳水、糖、纖維為克；B12 與維生素 D 為微克；其餘目前支援的礦物質、維生素、EPA、DHA、膽固醇為毫克；熱量為大卡。
- 所有 104 個分析項目的原始名稱、單位、分類與「每100克含量」字串，另存於 `foods/sources/tfda-complete/` 的 18 個分類快照。未支援的胺基酸、個別脂肪酸等仍可查閱，沒有丟棄或硬轉成介面欄位。
- 快照保留上述資料及來源前處理等基本資訊；樣本數、標準差與其他份量欄位未另存，需回到官方原始 ZIP 查詢。
- 生熟、泡發、去皮、加工及不同烹調條件依原名與前處理描述；原始未明示的狀態不自行補猜。不把生重值當作熟食，也不從來源狀態推導生食安全認證。
- 繪圖的 `shape`、`density=1` 為介面暫定估值，不是官方實測物性。`edibleRatio=1` 僅適用已去除不食部分的圖形，建議使用秤重；沒有把來源「廢棄率」再次套用在已是可食部分的營養值上。
- 份量按鈕統一為秤取可食部分 100 公克；油脂、糖及調味品採 5 公克，並非建議攝取量或單顆／湯匙重量。
- 中文介紹與小撇步只說明來源及計重條件，不從成分資料推導疾病預防效果。包裝食品仍優先參考實際標示。

## 大型資料庫的載入與更新

`foods/items/*.json` 仍是可編輯的資料來源；`foods/index.json` 列出食物檔案。
本次新增 `foods/catalog/`：每批最多 100 筆，共 28 批；內容與單筆 JSON 完全一致，檔名含內容雜湊。
App 正常啟動只需 31 次 JSON 請求（營養素、索引、快取清單與 28 批資料），最多 4 批並行。
快取缺失、過期或不完整時，自動退回最多 8 筆並行的逐筆載入。

新增或修改食物後執行 `node tools/build-index.mjs`，會一起產生索引與分批快取；不需另改程式。
